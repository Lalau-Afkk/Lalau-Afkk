"01" — Sobre mim

Olá! Sou Laura Souto de Oliveira, estudante de Técnico em Informática para Internet.

Tenho interesse na área de desenvolvimento web e estou construindo minha base em tecnologias que permitem criar páginas e experiências para a internet.

Atualmente, minhas tecnologias de estudo são:

- HTML — estruturação de páginas web.
- CSS — estilização e construção de interfaces.
- JavaScript — interatividade e comportamento das páginas.

Este perfil reúne meus estudos, minha evolução e os projetos que desenvolvo ao longo da minha jornada.
